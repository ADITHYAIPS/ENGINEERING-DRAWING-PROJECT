# Design and Fabrication of a Wooden Wall Mounted Stand

## Project Description

This project presents a wooden wall mounted stand designed to hold an item in a fixed and organized position while using wall space instead of floor or table space. The structure consists of a back panel, a projecting base platform, side support brackets and an upper cross member, fixed to the wall using keyhole-type mounting holes.

## Objectives

- Provide a fixed and organized place for an item
- Save floor and table space by mounting on the wall
- Keep the supported item retained within a defined area
- Develop a simple and stable wooden support structure

## Materials Used

- Wooden board / panel
- Wooden base platform
- Wooden side support brackets
- Upper cross member
- Fasteners / screws
- Paint / surface finish

## Features

- Wall mounted design
- Keyhole-type mounting holes
- Side support brackets for lateral restraint
- Compact and stable structure
- No power required

## Applications

- Homes
- Offices
- Hostels
- Classrooms
- Workspaces and storage areas
